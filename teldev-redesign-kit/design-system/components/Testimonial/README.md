A short client quote with attribution — real names and real roles once supplied, never invented ones in production.

**Anatomy.** Quotation mark accent (`primary`), `h5`-weight quote (short quotes read better at this size than long ones — keep to two sentences), an avatar placeholder, name (`label`) and role (`small`, `text-muted`).

**Accessibility.** The quote mark glyph is decorative (`aria-hidden`); the avatar, until real photography exists, needs no alt text (`alt=""`) since the name beside it already identifies the person.
