Shown wherever a list or table has nothing in it yet — an enquiries dashboard, a search result set.

**Anatomy.** A large muted icon, `h5` title, one line of `small` explanation, an optional secondary `Button` action.

**Accessibility.** The explanation should say what WILL appear and how ("When someone submits the contact form, it will show up here"), not just "Nothing here" — this is a content requirement as much as a visual one.
