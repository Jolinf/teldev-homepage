"How we work" — a four-step process band used on the homepage and service pages.

**Anatomy.** A numbered circle (`primary` fill) per step, an `h6` title and a `small` description.

**Motion.** Steps reveal 140ms apart; from `md` up, a connector line draws from each number towards the next as it appears.

**Layout.** Stacked on mobile, four columns from `md` (768px).

**Accessibility.** Mark the wrapper as `<ol>` in the real build so assistive tech announces "step 1 of 4".
