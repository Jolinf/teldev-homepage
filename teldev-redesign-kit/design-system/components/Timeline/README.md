The Nigeria-first → Africa-wide roadmap, shown on the About page.

**Anatomy.** A vertical rule with a dot per milestone. Completed milestones have a filled `primary` dot; upcoming ones an outlined dot.

**Motion.** Milestones reveal top to bottom, 140ms apart, each dot popping in as it appears.

**Accessibility.** Mark the list as `<ol>`. Status is stated in the copy ("Live today:" / "Planned:") as well as by the dot, never by fill alone.
