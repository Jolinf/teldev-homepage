A small status or category chip.

**Anatomy.** `label-sm` text, optional leading icon, tinted background at low opacity over the matching semantic text colour.

**Variants.** `neutral`, `brand`, `success`, `warning`, `danger`.

**Accessibility.** A status badge (success/warning/danger) always pairs its colour with an icon and a text word ("Warning: …") — never a bare coloured dot — so the status survives grayscale and colour-blindness.
