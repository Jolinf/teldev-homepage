A fixed-ratio box that reserves the exact space real photography will fill later — never a grey rectangle with no context.

**Anatomy.** A neutral `bg-subtle` fill, a centred icon plus a one-line label naming the ratio's typical use, and an optional caption-style art-direction note pinned to the bottom-left corner (e.g. "Team working alongside a client, natural light, real Lagos office").

**Variants.** `ratio`: `16x9` (hero, case studies), `4x3` (service cards), `1x1` (team/founder portraits), `3x4` (editorial/blog).

**Photographic style, once real photography replaces this component:** natural light, candid, real TELDEV people and real clients. Never a staged stock pose, never a generic desk-and-laptop stock photo.

**Accessibility.** When replaced with a real `<img>`, alt text describes the *content*, not "photo of" — e.g. `alt="Two TELDEV engineers configuring a server rack at a client's office"`. Purely decorative instances (rare) use `alt=""`.
