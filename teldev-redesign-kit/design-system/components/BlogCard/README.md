An article summary card for the blog index.

**Anatomy.** A photo (`ratio` `3x4` by default; use `4x3` in three-column grids) with the category `Badge` floating over its top-left corner, `h5` title, `small` excerpt, `caption` metadata (date · read time).

**Motion.** On hover the image zooms 3% and the title turns `link` colour.

**Accessibility.** The title link is stretched over the whole card, so the card is one link with one accessible name — no repeated "Read more" links.
